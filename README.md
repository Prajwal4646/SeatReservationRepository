# Seat Reservation App

This is a new Spring Boot project scaffolded for a seat reservation service.

## Run locally

```bash
./mvnw spring-boot:run
```

## Project structure

- `src/main/java` - application code
- `src/main/resources` - configuration and static resources
- `src/test/java` - tests

## Default configuration

The app runs on port `8080` and uses the default Spring Boot application configuration.
